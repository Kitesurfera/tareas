# Tareas

App web para repartir la carga mental en casa, empezando por la salud de la mascota: vacunas, desparasitaciones, medicación y peso, con una responsable clara para cada cosa.

Estado: en desarrollo (Fase 1). Las instrucciones del proyecto están en [CLAUDE.md](CLAUDE.md).

## Cómo arrancarlo en tu ordenador

Necesitas tener instalado [Node.js](https://nodejs.org) (versión 20 o superior).

```bash
npm install     # descarga las librerías que usa el proyecto (solo la primera vez)
npm run dev     # arranca la app en http://localhost:5173
```

Otros comandos útiles:

- `npm run build`: comprueba que todo compila y prepara la versión final.
- `npm run lint`: revisa el código en busca de errores comunes.
